# Font Source

Static weights extracted from Google Fonts' variable-font sources
(`google/fonts` GitHub repo, `ofl/inter` and `ofl/spacegrotesk`) using
`fonttools`'s variable-font instancer. Both Inter and Space Grotesk are
licensed under the SIL Open Font License, which permits bundling/embedding
in an application. See https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt
and .../ofl/spacegrotesk/OFL.txt for the full license text.
